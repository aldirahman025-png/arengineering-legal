Kebijakan Privasi

AREngineering · AREngineering Labs · berlaku sejak 18 Oktober 2026

Ringkasnya

AREngineering dibuat untuk bekerja offline. Data pengukuran Anda tetap di perangkat Anda. Tidak ada iklan, tidak ada pelacak pihak ketiga, dan data tidak dijual. Koneksi internet hanya dipakai untuk lisensi/akun, pemeriksaan pembaruan, laporan eror otomatis (bisa dimatikan), dan, bila Anda menyalakannya, cadangan di akun serta citra satelit/peta latar.

1. Data yang hanya tersimpan di perangkat

  • Proyek, titik koordinat, hasil hitungan, riwayat, laporan, pengaturan, dan progres belajar.
  • Lokasi GPS — hanya dibaca saat Anda menekan “Ambil posisi”, tidak dikirim ke mana pun.
  • File cadangan — disimpan di folder perangkat Anda (Documents/AREngineering/Cadangan).

2. Data yang dikirim ke server

  • ID perangkat acak buatan aplikasi (pada Android diturunkan secara satu arah dari ID perangkat) — untuk uji coba 7 hari dan aktivasi lisensi.
  • Nama pemegang lisensi, ID pembeli, paket, dan sidik (hash) kode lisensi — saat aktivasi dan pemeriksaan berkala (paling sering tiap 7 hari), untuk membatasi jumlah perangkat dan mencegah penyalahgunaan.
  • Bila Anda mengaktifkan lisensi sambil masuk akun: kode lisensi perangkat Anda disimpan pada akun agar dapat dipasang kembali setelah instal ulang, serta permintaan kode untuk perangkat baru.
  • Bila Anda membuat akun: email, nama, nickname (bila Anda membuatnya, untuk masuk tanpa mengetik email), jenjang pendidikan, dan foto kartu pelajar/mahasiswa untuk verifikasi harga khusus. Foto kartu disimpan di penyimpanan privat dan hanya dapat dilihat oleh Pemilik untuk verifikasi. Untuk mencegah tebak-tebakan kata sandi, percobaan masuk yang gagal dicatat sementara (nickname dan waktunya).
  • Pembayaran langganan diproses oleh Google Play / App Store dan RevenueCat; aplikasi tidak menerima nomor kartu atau rekening Anda.
  • Bila Anda menekan “Simpan ke akun” atau menyalakan cadangan otomatis ke akun: file cadangan (proyek, riwayat, pengaturan; tanpa lisensi, PIN, dan ID perangkat) disimpan di penyimpanan privat akun Anda. Hanya Anda yang dapat membukanya dari aplikasi; 10 cadangan terbaru disimpan dan Anda dapat menghapusnya dengan menghapus akun.
  • Bila Anda memakai Asisten AI: pertanyaan Anda, beberapa pesan terakhir percakapan, potongan materi Modul Belajar dan daftar alat yang relevan, ID perangkat acak, isian yang diisikan Asisten ke kalkulator beserta hasilnya, dan, hanya bila Anda menekan “Periksa hasil di layar ini” atau “Tulis narasi laporan”, isian dan hasil kalkulator yang sedang terbuka. Data ini dikirim melalui server Pemilik ke Anthropic (Claude) untuk dijawab dan tidak disimpan oleh Pemilik; yang dicatat hanya jumlah pertanyaan per hari untuk kuota. Sesuai ketentuan komersial Anthropic, data API tidak dipakai untuk melatih model.
  • Pemeriksaan pembaruan: aplikasi membaca daftar versi terbaru dan, bila ada, mengunduh paket pembaruan yang ditandatangani Pemilik. Tidak ada data Anda yang dikirim selain permintaan unduhan biasa.

Server yang dipakai: Supabase (basis data & penyimpanan), RevenueCat (status langganan), dan Anthropic (Asisten AI).

3. Peta & citra satelit (opsional)

Bila Anda menyalakan citra satelit atau peta latar di Layar Model / Layar Cetak, aplikasi mengunduh potongan gambar peta (tile) langsung dari penyedia peta — bawaan Esri World Imagery, pilihan OpenStreetMap atau Esri Topo, atau penyedia yang diatur pemilik aplikasi. Permintaan itu memuat nomor petak peta yang sedang dilihat (sehingga memperlihatkan perkiraan lokasi area yang Anda buka) dan alamat IP perangkat, dan tunduk pada kebijakan privasi penyedia tersebut. Titik, gambar, dan data proyek Anda tidak ikut dikirim. Bila citra dimatikan, tidak ada permintaan peta.

4. Laporan masalah

Laporan eror otomatis: bila terjadi galat, aplikasi mengirim versi aplikasi, jenis dan sistem HP, ID perangkat acak, nama alat yang sedang dibuka, serta pesan galat ke server Pemilik untuk memperbaiki aplikasi. Data proyek, koordinat, dan isian Anda tidak ikut. Anda dapat mematikannya di Pengaturan → Tentang & dukungan → “Kirim laporan eror otomatis”.

Bila Anda menekan “Kirim laporan masalah”, teks laporan (versi aplikasi, ID perangkat, jenis perangkat, dan catatan galat) dikirim melalui WhatsApp atau email yang Anda pilih sendiri.

5. Penyimpanan & penghapusan

Data aktivasi disimpan selama lisensi berlaku. Anda dapat menghapus akun dari menu Akun → Hapus akun: akun, profil, nickname, foto kartu, cadangan di akun, kaitan lisensi ke akun, dan catatan kuota Asisten AI dihapus permanen; laporan eror yang pernah terkirim dilepas dari akun Anda. Anda juga dapat meminta penghapusan data lisensi melalui aldirahman025@gmail.com. Data di perangkat terhapus bila aplikasi dihapus atau data aplikasi dibersihkan.

6. Pengguna di bawah umur

Paket Pelajar ditujukan untuk siswa SMK/SMA. Pengguna di bawah 18 tahun sebaiknya memakai aplikasi dengan sepengetahuan orang tua, wali, atau sekolah.

7. Keamanan

Komunikasi ke server memakai HTTPS. Kode lisensi ditandatangani secara digital (ECDSA P-256). PIN disimpan sebagai hash (PBKDF2), bukan teks asli.
